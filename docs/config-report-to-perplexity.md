## Найденные проблемы

### Проблема 1 (критическая): парсер `+` не соответствует стандартной покерной нотации

Файл `rangetool/range_parser.py`, функция `_expand_non_pair_plus()`. Оператор `+` для не-парных рук меняет **только кикер**, фиксируя старшую карту:

```python
# Текущее поведение:
# KJs+ → {KJs, KQs}           (только K-high suited)
# JTs+ → {JTs}                 (только JTs)
# KJo+ → {KJo, KQo}           (только K-high offsuit)
```

**Стандартная покерная нотация:** `KJs+` = "KJs и все лучшие suited руки" = KJs, KQs, AJs, AQs, AKs.

**Последствия:** все ренджи в конфиге значительно **уже**, чем задумано:
- `KJs+` задумано как ~5 suited рук → парсер даёт 2
- `JTs+` задумано как ~4 suited руки → парсер даёт 1

Реальные ширины ренджей получаются на 5-10 процентных пунктов ниже ожидаемых.

### Проблема 2: BTN — 33 в call но не в push

```
call deep: 33+, ...    ← 33 включена (6 комбо)
push deep: 44+, ...    ← 33 НЕ включена
```

Если ты готов коллировать олл-ин с 33, то open-shove с 33 тем более +EV (есть fold equity). 33 должна быть в push, если она в call. Нарушение принципа `call ⊆ push`.

### Проблема 3: BB — KJo/KQo в call но не в push

```
call deep: ..., KJo+, ...   ← KJo, KQo включены (24 комбо)
push deep: 22+, Axo, Axs, Kxs+, Q8s+, QTo+, JTs+  ← KJo, KQo НЕ включены
```

Push содержит `Axo` (A-high offsuit) и `QTo+` (Q-high offsuit), но K-high offsuit полностью пропущен. Если KQo достаточно хорош для колла олл-ина, он тем более хорош для open-shove.

### Проблема 4: общая ширина ренджей возможно занижена

Текущие ширины deep push:
- BTN: 16.7%
- SB: 11.8%
- BB: 27.0%

Для 3-max 15bb эти цифры выглядят консервативно. Для сравнения:
- В хедз-ап push-fold на 15bb оптимальный пуш-рендж SB ≈ 48%
- В 3-max с учётом ICM, BTN должен пушить ~30-35%, SB ~20-25%, BB ~35-45% (BB защищает blinds, получает pot odds)

## Что спросить у Perplexity (Sonnet / Deep Research)

1. **Оптимальные push/fold ренджи для 3-max турнира 15bb (без анте).** Какие руки должен open-shove BTN, SB, BB при эффективном стеке 15bb? Учитывать ICM (50/30/20 payout structure).

2. **Должен ли push-рендж быть шире call-ренджа для каждой позиции?** Теоретически: open-shove имеет fold equity, call shove — нет. Значит push ≥ call всегда. Верно ли это для всех позиций в 3-max?

3. **Как меняются оптимальные ренджи при уменьшении стека с 15bb до 2bb?** Нужна таблица или кривая: ширина push-ренджа BTN/SB/BB на 15bb, 12bb, 10bb, 8bb, 6bb, 4bb, 2bb.

4. **Какие hands являются маргинальными (breakeven) на границе push/fold для каждой позиции при 15bb?** Например: является ли 33 пушем с BTN? Является ли KQo пушем с BB? Это поможет откалибровать границы ренджей.

5. **Реалистичные дефолтные ренджи оппонентов для 3-max low-stakes (микролимиты).** Насколько широко реальные игроки коллят/пушат в $0.50-$2 JAQKpot по сравнению с GTO?
